## What is SASS and How does it work &mdash;

### SASS

Sass is a CSS preprocessor, an extension of CSS that adds power and elegance to the basic language.

    SASS SOURCE CODE -> Sass Compiler -> COMPLIED CSS CODE

### MAIN SASS FEATUREs

- `Variables` : for reusable values such as `colors`, `font-sizes`, `spacing`, etc.

- `Nesting` : to nest selectors inside of one another, allowing us to write less code.

- `Operators` : for mathematical operations right inside of CSS:

- `Partials and imports` : to write CSS in different files and importing them all into one single file:

- `Mixins` : to write reusable pieces of CSS code;

- `Function` : similar to mixins, with the difference that thty produce a value that can than be used.

- `Extends`: to make differnt selectors inherit declarations that are common to all of them;

- `Control driectives`: for writing complex code using conditionals and loops (not covered in this course)

### SASS FORM &mdash;

```sass

    .navigation
        list-style: none
        float: left

        & li
            display: inline-block
            margin-left: 30px
```

```scss

  float: left;

    display: inline-block;
    margin-left: 30px;
  }
```
